Öt perc alatt kezdhető

  1. Állítás: egy ellenőrizhető mondat, pontosan megfogalmazva.
  2. Forrás: fájl, oldal vagy beszélgetés és a visszakereshető helye.
  3. Dátum alapja: különítsd el a szöveg belső dátumát a külső feltöltéstől.
  4. Ellenadat: a hiányzó vagy ellentmondó rész is a történethez tartozik.
  5. JSON mentés: minden érdemi munka végén tölts le egy példányt.

A „bizonyosság” az adott megfigyelésre vonatkozik. Egy feltöltés ideje lehet erős adat, miközben a dokumentumban leírt korábbi esemény ideje még nyitott.

A JSON import elfogadja a saját exportját és az {"entries":[...]} alakú auditnaplót motif, observation, alternative_explanation mezőkkel. A betöltés felülírja az aktuális lapot: előtte ments JSON-t.
